## Когда понадобится источник, которому это важно (RemoteOK, v2 ATS)

- `canonical_url`: URL без схемы превращается в мусор; порт по умолчанию не убирается;
  `_DROP_PARAMS` выкидывает общие `source`/`src`/`u`.
- URL-шаг дедупа игнорирует компанию (общая страница карьеры склеила бы разные роли).
- `fetch_feeds` вызывает `key()` вне per-feed `try`; записи без id/guid схлопываются в один ключ.
- Himalayas: разбор страницы 2+ вне `try`; страница без `pubDate` останавливает обход;
  «все смещения» по усечению `int()` — эвристика (точная проверка: `set(range(-11, 15)) <= set(offsets)`).
- Himalayas: при смене формата (`parentCategories` пропал) источник покажется `empty`, а не `degraded`.

## Косметика / тесты, по случаю

- Стоп-слова из 2 букв («in», «of», «qa») считаются маркерами → «Engineer in Test» и
  «Engineer Test» не склеятся (консервативно, намеренно).
- Не все формы гендерных пометок убираются («(m/w/divers)», «[all genders]») — только пропуск склейки.
- WWR: навыки делятся по голому « and » («Machine Learning and AI» → два тега).
- Недостающие тесты: `make_engine`, round-trip `%` в `alembic_config`, downgrade, дробные
  смещения часовых поясов, смешанные даты в lookback, `call_count` в тесте нескольких индустрий Jobicy.
- Нет `server_default` у NOT NULL колонок (важно только для не-ORM писателей); нет индекса на
  `source_runs.run_id`.
